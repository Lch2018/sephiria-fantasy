首个 Modrinth 发布，对应仓库里的 `v0.1.10.9-a`（同一天更早在 GitHub 上发过一个内容相同的 `v0.1.0-a`，命名改成日期制之后重发）。

这一版包含：

- 六把基础武器（刀 / 巨剑 / 匕首 / 盾剑 / 长棍 / 法杖），各自的普攻手感与武器技能；
- 十套「连击」与 55 件神器，凑齐同套神器提升连击档位；
- 触电 / 灼伤两套减益（按层数结算，敌人脚下有层数标签），减益伤害与真实伤害都能暴击；
- 神器技能系统（6 个技能栏 + 可绑定按键）；
- 十余项属性、两列属性页（悬停出算式）；
- 商店（可刷新货架、谈判力折扣）与三种宝箱；
- 红蛇之眼陨石的四段演出、太阳剑划痕、雷之裁决光束、乌云雷击等特效，以及自定义粒子与程序生成的音效；
- 背包 / 附魔 / 宝箱 / 商店页面的背景虚化与背包连击栏滚动。

注意：这是 **A 测**版本，大部分内容尚未充分实测，数值与手感仍会调整。
