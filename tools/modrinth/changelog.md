## English

This is a **metadata and wording** update only: the mod's content is identical to `0.1.10.11-a` (no need to re-test gameplay) — everything changed is what other people see about the project.

### Fixes

- **Author**: the mod list showed a made-up "SEPHIRIA Mod Team"; it is now the actual author, **Lch2018**;
- **Links**: the repository homepage and issue tracker are filled in, so the "Website" / "Issues" buttons in the mod list work;
- **License field**: it used to be `LicenseRef-Sephiria-Fan-Mod-NonCommercial` — an **undefined custom license reference** (per SPDX, a `LicenseRef-` must be defined in an SPDX document, otherwise tools cannot resolve it), and it did not match what Modrinth showed. It is now `CC-BY-NC-4.0`. The terms themselves are unchanged: the full text is still the repository [LICENSE](https://github.com/Lch2018/sephiria-fantasy/blob/main/LICENSE) (the fan-made mod license notice).

### Disclaimer rework

The disclaimer now follows the usual fan-mod shape — **license → fan project → AI-generated code → asset exception → trademarks**. The asset clause is stricter: it names the rights holder (**TEAM HORAY**), states that this project's license covers only the code / data / scripts / docs written for it, and says that the weapon artwork **may not be extracted, redistributed separately, or used commercially** (with a takedown-on-request closing line).
